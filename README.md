# Adeel Ahmad's Academic Website

This is the source code for my personal academic website, showcasing my research in remote sensing, GIS, and geospatial data science.

## About

I am an **Assistant Professor** at the [Institute of Geography](https://www.pu.edu.pk/), University of the Punjab, Lahore, Pakistan, and Lab Director of **GeoScape Analytics Lab (GSAL)** — a research-led startup lab specializing in remote sensing, GIS, GeoAI, and spatial data science.

### Research Interests
- Remote Sensing and GIS applications
- Geospatial Artificial Intelligence (GeoAI)
- Open geospatial data infrastructure for Pakistan
- Machine learning for environmental monitoring
- Landslide hazard and vulnerability assessment
